# 模块一：事件识别能力

## TC-1.1：基本状态变化 — 角色身份变更

```json
[
  {
    "title": "辞去工作成为自由职业者",
    "summary": "用户决定辞去当前工作，已提交辞职信，转为自由职业者",
    "importance": 7,
    "participants": ["用户"],
    "location": "",
    "tags": ["职业变化", "身份转变"]
  }
]
```

**验证点**:
- ✅ 角色身份/状态变化被正确识别
- ✅ 对话过程（AI 的确认询问）未被记录为独立事件
- ✅ 重要性评分符合重大事件（7-8）
